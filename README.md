# English Learning System

منصّة تعلّم إنجليزية تفاعلية لمدّة 9 أشهر (36 أسبوعاً).

## 🎯 الهدف
بناء منهج يومي تفاعلي بـ Markdown يُحوَّل تلقائياً إلى HTML ويُنشر على GitHub Pages.

## 📂 البنية
| المجلّد | الوصف |
|---------|--------|
| `content/` | دروس المدرّس بصيغة Markdown |
| `weeks/` | HTML المُولَّد من Markdown |
| `shared/` | CSS و JS مشتركان |
| `templates/` | قوالب HTML |
| `reports/` | نموذج التقرير اليومي |
| `_scripts/` | سكربتات البناء (Node.js) |

## 🚀 الرابط الحيّ
انظر `LIVE_URL.txt` (يُنشأ بعد تفعيل GitHub Pages).

## 📜 الترخيص
الاستخدام الشخصي والتعليمي.
